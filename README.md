
# Python Essentials for AI 🐍

This repository is a collection of practice projects that form the foundation of my learning journey toward AI Engineering.  
These projects focus on working with data, strings, and core algorithmic logic, which are essential building blocks for machine learning and AI development.

## 📁 Project Structure
- Calculator Suite: Salary calculation programs using conditional logic.
- String Manipulation: String slicing and text searching (foundational skills for text processing and NLP).
- Text Analysis: Reading log files, filtering spam emails, and analyzing word frequency (an introduction to working with datasets).

## 🚀 Skills Applied
- Python 3.12+ (Type Hinting, Core Data Structures)
- File I/O (Reading and processing text files)
- Algorithmic Thinking (Finding most frequent elements)
- Clean Code & Readability Practices
